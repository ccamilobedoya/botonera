# ADR-0001 · El dueño aprueba stack, arquitectura y tecnología

- **Estado:** aceptada
- **Fecha:** 2026-11-04 · **Decidió:** dueño del proyecto

## Contexto

El proyecto lo construyen agentes a partir de fichas que escribe el arquitecto. Sin una regla clara, las propuestas del arquitecto se cuelan como decisiones.

## Decisión

Toda decisión de stack, arquitectura, dependencias, publicación y tecnología la aprueba el dueño. Lo demás se marca «propuesta» hasta que la apruebe. Dos puertas por ficha: la ficha antes de programar y el resultado antes de integrar.

## Consecuencias

Las fichas llevan las decisiones numeradas; nada se construye sobre una propuesta sin aprobar.
