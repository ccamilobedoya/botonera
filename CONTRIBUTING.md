# Contributing to botonera

Thanks for helping. Please open an issue before a large change, so we can agree on it first.

## Before you open a pull request

1. Run `scripts/setup` once to install the git hooks and the tools.
2. Run `scripts/review`; it must finish without findings.
3. Keep the change small and focused, and update the documents it affects.
4. Describe what changed and why in the pull request.

## Reporting problems

Use the bug template in the issue tracker. For security problems, follow [SECURITY.md](SECURITY.md) instead.
